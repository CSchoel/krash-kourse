# Krash Kourse v4 - Using helm

Writing both a `Deployment` and `Service` to deploy LanguageTool in a Kubernetes cluster involves writing a lot of yaml that feels a bit like boilerplate code.
Everyone who does this in any Kubernetes cluster will have to write something similar with maybe 80-90% overlap.

So why make everyone do this if you can just provide a "package" to install in Kubernetes with a few customization options.
That is exactly what [Helm](https://helm.sh/) was created for.
And luckily for you, I've already written a [rudimentary helm chart for LanguageTool](https://github.com/CSchoel/brood-chamber/tree/main/charts/languagetool).

## 1 Install helm

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-4 | bash
```

## 2 Install helm chart

_TODO: I want to make this nicer by creating a proper [chart repository](https://helm.sh/docs/topics/chart_repository/) in the future._

```bash
# Delete previous deployments
kubectl delete deployment lt-deployment
kubectl delete service lt-service
# Get the helm chart
git clone git@github.com:CSchoel/brood-chamber.git
cd brood-chamber
# First check out the manifests generated by the chart
helm install --dry-run=client lt charts/languagetool
# Then actually install them
helm install lt charts/languagetool
```

## 3 Inspect and test the resulting deployment

```bash
kubectl get all -l app.kubernetes.io/name=languagetool
curl http://127.0.0.1:30080/v2/check -d text="Its fine." -d language=en
```
