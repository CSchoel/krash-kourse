# Krash Kourse v4 - Using helm

Writing both a `Deployment` and `Service` to deploy LanguageTool in a Kubernetes cluster involves writing a lot of yaml that feels a bit like boilerplate code.
Everyone who does this in any Kubernetes cluster will have to write something similar with maybe 80-90% overlap.

So why make everyone do this if you can just provide a "package" to install in Kubernetes with a few customization options.
That is exactly what [Helm](https://helm.sh/) was created for.
And luckily for you, I've already written a [rudimentary helm chart for LanguageTool](https://github.com/CSchoel/brood-chamber/tree/main/charts/languagetool).

## 1 Install helm

### Linux

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-4 | bash
```

### macOS

```bash
brew install helm
```

### Windows

Download the latest [canary build](https://helm.sh/docs/intro/install/#from-canary-builds) (or use Chocolatey (`helm`), Scoop (`helm`), or Winget (`Helm.Helm`)).

## 2 Clean up previous deployments

```bash
# Delete previous deployments
kubectl delete deployment lt-deployment
kubectl delete service lt-service
```

## 3 Add the Helm chart repo

```bash
helm repo add brood-chamber https://cschoel.github.io/brood-chamber/
```

## 4 Check out the manifests generated by the Helm chart

```bash
# First check out the manifests generated by the chart
helm install --dry-run=client lt brood-chamber/languagetool
```

> Expected output (abbreviated):
>
> ```plain
> NAME: lt
> LAST DEPLOYED: Mon Mar 23 18:02:02 2026
> NAMESPACE: default
> STATUS: pending-install
> REVISION: 1
> DESCRIPTION: Dry run complete
> HOOKS:
> ---
> # Source: languagetool/templates/tests/test-connection.yaml
> apiVersion: v1
> ...
> ```

## 5 Install the Helm chart

```bash
helm install lt brood-chamber/languagetool
```

> Expected output:
>
> ```plain
> NAME: lt
> LAST DEPLOYED: Mon Mar 23 18:05:46 2026
> NAMESPACE: default
> STATUS: deployed
> REVISION: 1
> DESCRIPTION: Install complete
> NOTES:
> 1. Get the application URL by running these commands:
>   export NODE_PORT=$(kubectl get --namespace default -o jsonpath="{.spec.ports[0].nodePort}" services lt-languagetool)
>   export NODE_IP=$(kubectl get nodes --namespace default -o jsonpath="{.items[0].status.addresses[0].address}")
>   echo http://$NODE_IP:$NODE_PORT
> ```

## 7 Test the deployment

```bash
curl http://127.0.0.1:30080/v2/check -d text="Its fine." -d language=en-US
```

> Expected output (abbreviated):
>
> ```plain
> {"software":{"name":"LanguageTool","version":"6.7" ... }
> ```

## 8 Cleanup

```bash
helm uninstall lt
```
